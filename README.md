## Projenin Hedefleri: Bu asistanın ilerleyen zamanlarda hangi özellikleri kazanacağını
(örneğin v1.0 Akıllı Menü, v2.0 Veri Saklama) maddeler hâlinde yazınız.

>2. Adım: saat = 1 olarak ayarla. 
>3. Adım: Sensörden o saatteki su seviyesi bilgisini oku (su_seviyesi). 
>4. Adım: EĞER su_seviyesi > 50 İSE 7. Adım’a git (Döngüyü kır). 
>5. Adım: Kapakları kapalı tut, saat = saat + 1 yap. 
>6. Adım: 3. Adım’a geri git. 
>7. Adım: Ekrana tahliye saatini (saat) ve kritik su seviyesini (su_seviyesi) yazdır.
